# Product vision

## BytLot

**Know the real number.**

BytLot makes the meaningful number visible when an advertised, gross, monthly, or headline number is incomplete. A product belongs only when it can clearly answer: what number the user sees, why it is incomplete, what number they need instead, and how BytLot can calculate it transparently.

## Principles

- Useful, clear, and trustworthy beats feature volume.
- Label user inputs, defaults, assumptions, estimates, and calculated outputs distinctly.
- Use the least complex architecture that provides the value.
- Prefer evidence over enthusiasm; classify claims as measured, externally supported, hypothesis, or insufficient data.

## Product sequence

Driver Profit is the current MVP. Phone Cost and EV Cost are candidates, not commitments; build neither until fresh evidence supports it.
